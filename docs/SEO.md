# Kelvin: SEO и запуск индексации

Основной сайт: https://kelvin-iota.vercel.app

## Что реализовано

- Собственный canonical, заголовок, описание и Open Graph URL для каждой страницы.
- Взаимные языковые ссылки ru / pt-BR / x-default, одинаковые в HTML и sitemap.
- robots.txt с разрешённым обходом страниц и ссылкой на карту сайта; API исключён из обхода.
- sitemap.xml: 14 публичных страниц, без редиректов и выдуманных дат обновления.
- SoftwareApplication только на главных страницах: реальная версия, минимальная macOS, бесплатная цена и проверенная ссылка загрузки.
- Три руководства в двух языках, доступные по обычным HTML-ссылкам с главной: температура, вентиляторы, лимит заряда MacBook. BreadcrumbList на каждом руководстве.
- Серверный HTML и предварительная генерация страниц; уникальные H1 и содержательные тексты.
- Адрес сайта задаётся в lib/seo.ts. NEXT_PUBLIC_SITE_URL позволяет переопределить origin при переходе на подтверждённый собственный домен. Не ставьте туда временный preview URL.

## Проверка перед публикацией

Из kelvin-web/:

```sh
npm run check
npm start -- --port 3100
node scripts/verify-release.mjs http://localhost:3100
node scripts/verify-seo.mjs http://localhost:3100
```

При изменении основного домена передайте его третьим аргументом verify-seo.mjs.
После публикации повторите verify-seo.mjs с основным адресом сервера.

## Действия в кабинетах поисковиков после публикации

1. Добавьте URL-prefix property `https://kelvin-iota.vercel.app/` в Google Search Console. Для общего домена vercel.app используйте проверку через HTML-файл или meta-тег, а не DNS всего vercel.app. Полученный HTML-файл можно положить в kelvin-web/public/ без изменения содержимого и опубликовать. Код проверки выдаётся владельцу в Search Console; не придумывайте его.
2. Отправьте `https://kelvin-iota.vercel.app/sitemap.xml` в разделе Sitemaps.
3. Через URL Inspection проверьте /ru, /pt и руководства; запросите индексацию основных страниц. Убедитесь, что выбранный Google canonical совпадает с адресом текущей страницы.
4. Добавьте тот же сайт и карту сайта в Яндекс Вебмастер и Bing Webmaster Tools, пройдя их проверку владения.
5. Следите за индексированием, запросами, показами, кликами и CTR отдельно по языкам. До подтверждения владения и накопления данных эти показатели неизвестны.
6. Core Web Vitals оценивайте по реальным данным Search Console / PageSpeed Insights. Проверка сборки и HTML сама по себе не является измерением скорости.

## Что ещё важно

SEO-изменения не гарантируют индексацию, конкретные позиции или срок появления в выдаче. Следующие решения о контенте принимайте по реальным запросам и показам, а не путём массового создания однотипных страниц. Упоминания и ссылки должны появляться в релевантных местах, где Kelvin действительно полезен.

trykelvin.com на момент проверки отдавал JavaScript-переход на /lander. Он исключён из SEO-адресов сайта. Упоминания native Sparkle update feed в политике конфиденциальности и старые appcast-файлы описывают отдельный механизм приложения и этим SEO-изменением не менялись.
